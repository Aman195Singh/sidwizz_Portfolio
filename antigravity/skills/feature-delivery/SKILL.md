# Feature Delivery Skill
Map requirement to route, data, action and tests. Inspect existing code. Plan files. Validate server inputs. Check authorization. Implement loading/empty/error/success states. Add unit/integration/E2E tests. Test keyboard and responsive behaviour. Run lint/typecheck/build. Update traceability and report verified results.
