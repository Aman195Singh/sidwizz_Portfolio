# 13 — SEO, Accessibility and Performance

SEO: unique metadata, canonical, OG, sitemap of published routes only, robots excluding admin/preview, stable slugs/redirects, valid JSON-LD only. Do not use unverified review schema.

Accessibility: target WCAG 2.2 AA core journeys; keyboard navigation, visible focus, labels/errors, contrast, alt text, reduced motion, accessible lightbox and calendar, status not colour-only.

Performance: server components by default, responsive optimized images, lazy embeds, pagination, no autoplay sound, explicit image dimensions, small client bundles, pooled Neon connections, no admin caching. Measure actual deployed Core Web Vitals; do not claim unmeasured scores.
