# 03 — Page Behaviour Specification

- **Home:** hero with approved portrait/event image, positioning, booking/showreel CTAs, verified proof points only, intro, services, selected work, showreel, approved testimonials, CTA.
- **About:** approved short/long bio, verified timeline, hosting philosophy, strengths/languages, approved portrait.
- **Services:** owner-managed title, summary, description, inclusions; hide prices unless approved.
- **Portfolio:** category/year filters only where data exists; responsive cards, empty filter state and pagination.
- **Case study:** title, permitted date/location, hero media, brief, role, challenge, approach, outcome, gallery, approved testimonial and CTA; hide empty sections.
- **Gallery:** category filters, responsive grid, accessible lightbox, keyboard controls, alt text, approved rights only.
- **Videos:** showreel and categories; poster-first, click-to-play, no autoplay sound; provider allowlist.
- **Testimonials:** genuine permission-confirmed content only; publishing blocked without permission.
- **Media Kit:** short/long bio, verified facts, approved photos, selected work and contact; PDF is P1 unless owner requires it for launch.
- **Blog:** published posts only; structured rich text, sanitised links/media, metadata, private draft preview.
- **Booking:** public date state Available/Tentative/Unavailable; missing row = “Check with us”; enquiry is not confirmation.
- **Contact:** approved contact methods and form; no private number without owner approval.
- **Privacy/Terms:** must reflect actual data handling and receive owner/legal review.
